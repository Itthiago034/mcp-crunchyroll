# Launch materials

Drafts for a future public release. The repository is currently private; do not share its link as a public installation source until it is accessible and its contents and history have been reviewed.

## Short introduction — English

I’m working on an unofficial Crunchyroll MCP server for personal AI agents. It supports catalog searches, series and episode details, watch history, watchlists, and recommendations through an interactive browser sign-in.

The v0.1.0 server does not play or download video. I’d welcome feedback on setup, documentation, and which integrations would be useful.

Repository: https://github.com/Itthiago034/mcp-crunchyroll

## Apresentação curta — português

## Demo outline — to be recorded, not an existing recording

1. Introduce the project and show the client connected to the local server.
2. Explain that sign-in happens interactively in the managed browser. Do not display the login, browser profile, cookies, account information or tokens.
3. Show a search request for an anime and the returned series information.
4. Show a request for seasons or episodes and the resulting summary.
5. Close with the repository link, the unofficial status, and the fact that v0.1.0 does not play video.

Use a test account or sanitized data for any account-specific feature, and verify the recording before sharing. Results depend on the service and region.
